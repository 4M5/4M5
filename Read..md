## 🧠 What I actually build

Not a list of tutorials I followed — these are systems I designed, debugged at 2am, and shipped.

<table>
<tr>
<td width="50%" valign="top">

### 🔍 Multimodal RAG Retriever
**`paper-element-retriever`**

A retrieval system for research papers that doesn't just chunk text — it understands figures and tables too. ChromaDB for vector storage, Ollama running LLaMA 3.1 for reasoning and LLaVA for visual grounding.

`ChromaDB` `Ollama` `LLaMA 3.1` `LLaVA`

</td>
<td width="50%" valign="top">

### 🖱️ Virtual Mouse
**`Virtual-Mouse-Gesture`**

Control your cursor with gestures, voice, or your eyes — no hardware. Runs at 25 FPS using MediaPipe for real-time landmark tracking.

`MediaPipe` `OpenCV` `Real-time CV`

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🗣️ RAT-SQL Text-to-SQL
Translates plain English into executable SQL using a relation-aware transformer. Benchmarked on Spider — **73% exact match**, **63% execution accuracy**.

`Transformers` `NLP` `Spider Benchmark`

</td>
<td width="50%" valign="top">

### 🕵️ Exam Anomaly Detection
**`neurobots-hackathon-2026`**

Built at an IIT Palakkad hackathon — flags cheating behavior in online exams using an Isolation Forest model on behavioral signals.

`Isolation Forest` `Anomaly Detection`

</td>
</tr>
</table>
